# KHU Tutor Win64 후보 패키지 설치

이 패키지는 UE 5.8 Win64에서 플러그인 설치와 로드를 확인하는 내부 검수용 후보본이다. 학생 배포 완료본으로 사용하지 않는다. Claude Code 실행 파일은 포함하지 않는다. 학교 ChatKHU 경유 실행의 제공 조건과 학생용 런타임 설치 경로 확인이 남아 있다.

## 설치 환경

- Windows x64와 이 후보본을 빌드한 UE 5.8 설치본. 다른 엔진 패치나 BuildId이면 별도 빌드가 필요할 수 있다.
- 엔진에 포함된 ToolsetRegistry와 그 엔진 의존 플러그인이 있어야 한다. 패키지는 엔진 플러그인을 재배포하지 않는다.
- ModelContextProtocol은 학생 제품의 필수 의존이 아니다. 수동 MCP 서버·터미널·Node.js·전역 CLI 설정을 준비할 필요가 없다.
- 실제 질문에는 개인 ChatKHU API 키와 네트워크 연결, 사용 가능한 크레딧이 필요하다. 개인 월 한도는 ChatKHU가 관리한다.

## 플러그인 설치 확인

1. 대상 에디터를 닫는다. 기존 설치가 있다면 프로젝트와 플러그인 폴더를 먼저 백업한다.
2. 압축을 풀고 후보본 안의 `KHUTutor` 폴더를 대상 프로젝트의 `Plugins` 아래에 복사한다. `프로젝트/Plugins/KHUTutor/KHUTutor.uplugin` 구조여야 한다.
3. UE 5.8에서 Blueprint 전용 프로젝트를 연다. 플러그인을 활성화하고 필요하면 에디터를 재시작한다.
4. `Window → KHU Tutor`를 연다. Blueprint Editor에서도 같은 메뉴로 해당 자산의 패널을 열 수 있다.
5. C++ 빌드나 모듈 재빌드를 요구하면 진행하지 말고 엔진 버전·BuildId·중복 설치를 확인한다. 현재 후보본과 다른 엔진을 위한 DLL을 복사하지 않는다.

사용자 화면 검수는 패널 열기, C++/CS 실습 선택과 입력 보존, 문제 해결 기록의 저장·재열기·확인 후 복사까지 진행한다. 실제 질문과 노드 이동은 승인된 런타임이 준비된 환경에서 이어서 검수한다. 새 프로젝트 헤드리스 로드는 화면 사용성 검수와 구분한다.

2026-10-26 rc4부터 학생용 설정은 `templates/Config`를 기준으로 패키지에 반영한다. 기본 T1의 요청 반복 상한은 3회, T2는 5회이며 작업 예산은 soft 240 / hard 800 크레딧이다. 반복 상한이나 soft 예산으로 일시정지되면 알림의 ‘계속하기’로 이어가거나 ‘여기서 멈추기’로 끝낼 수 있다. hard 예산에서는 계속할 수 없다. 개발 환경의 20회 설정은 학생 패키지에 포함하지 않는다.

## API 연결과 오류

승인된 Claude 런타임이 준비된 환경에서 설정 화면에 본인의 ChatKHU 키를 입력하고 연결을 확인한다. 키는 해당 프로젝트의 Saved/KHUTutor에 Windows DPAPI로 보호해 저장하며 배포 패키지에는 넣지 않는다. 키 발급·학교 계정 권한은 학교 안내를 따른다.

| 화면 또는 현상 | 확인할 내용 |
|---|---|
| Claude 연결 프로그램이 준비되지 않음 | 이 후보본은 실행 파일을 포함하지 않는다. 담당자가 확인한 런타임 제공 절차가 필요하다. MCP 서버를 수동 실행해도 해결되지 않는다. |
| 인증 실패 | 키의 오타·만료·학교 계정 권한을 확인한다. 키를 오류 보고나 화면 공유에 노출하지 않는다. |
| 잔액 조회 실패 또는 미확인 | 정상 인증이나 잔액 0으로 해석하지 않는다. 네트워크와 서비스 상태를 확인한다. |
| 크레딧·작업 예산 안내 | 실제 전송은 크레딧을 사용한다. 작업 예산과 개인 월 한도는 다른 값이다. |
| 응답 중단·시간 초과 | 질문을 보존하고 연결을 확인한다. 중단된 요청도 비용이 생겼을 수 있다. |
| 모듈을 찾을 수 없음 | 압축이 완전히 풀렸는지, DLL과 UnrealEditor.modules가 있는지, UE 버전이 일치하는지 확인한다. |

튜터는 L0~L3 도움을 제공한다. AI 답변의 코드·원인·검증 주장은 직접 확인해야 한다. L4 변경 대행은 비활성이다. 학생 C++ 코드를 자동 수정하거나 빌드하는 기능은 제공하지 않는다.

## 제거와 데이터

에디터를 닫고 프로젝트의 Plugins/KHUTutor 폴더를 제거한다. 대화·과정 기록·피드백·보호된 키는 프로젝트 Saved/KHUTutor에 남으므로 필요한 기록을 먼저 백업한다. 해당 데이터 삭제는 학생이 직접 선택하며 플러그인 제거가 기록을 자동 삭제하지 않는다.

## 제공 조건과 고지

Claude Code는 Anthropic의 별도 소프트웨어다. 현재 [공식 제품 제공 조건](https://code.claude.com/docs/en/legal-and-compliance#can-customers-offer-claude-code-in-their-products)은 제품 내 실행에 바이너리 무변경과 사용자 인증·사용료 처리 조건을 명시한다. 학교 게이트웨이 경로에 적용되는 계약 확인이 필요하므로 이 후보본은 CLI를 재배포하거나 학생용으로 설치하지 않는다. 이는 학교 계약의 허용 여부를 판정한 결과가 아니다.

Unreal Engine 및 엔진 플러그인은 Epic의 제공 조건을 따른다. ToolsetRegistry는 사용자의 엔진 설치본에서 제공받으며 후보 패키지에 복사하지 않는다. KHU 자체 코드의 외부 배포 라이선스 확정도 일반 공개 배포 전에 확인한다. 내부 검수용 빌드 성공을 배포 허가나 학교 인증 완료로 해석하지 않는다.
